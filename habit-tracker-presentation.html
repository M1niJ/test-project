앱 소개

작은 행동의 반복이 삶을 바꿉니다.
매일의 습관을 시각화하고, 연속 달성으로 동기를 유지하는 웹 앱입니다.

Problem

왜 습관은 계속 실패할까요?

작심삼일의 근본 원인은 피드백의 부재입니다. 잘 하고 있는지, 얼마나 이어지고 있는지 눈에 보이지 않으면 동기는 금방 사라집니다.

💡

연구에 따르면, 목표를 '기록'하는 것만으로 달성률이 33% 높아집니다. 우리는 시각화된 피드백으로 그 효과를 극대화합니다.

Features

핵심 기능 한눈에 보기

복잡한 설정 없이, 켜자마자 바로 사용할 수 있도록 설계했습니다.

🔵

링 프로그레스

오늘의 달성률을 원형 게이지로 직관적으로 표시. 0 → 100% 애니메이션으로 성취감 극대화.

🔥

스트릭 카운터

습관을 연속으로 달성한 일수를 자동 계산. 연속 기록이 끊기지 않으려는 심리를 활용.

📅

주간 캘린더 스트립

오늘 기준 ±3일 달력을 상단에 표시. 요일별 색상 구분(토/일)으로 한눈에 파악.

✨

빠른 추가 칩

물 마시기, 운동, 독서 등 자주 쓰는 습관을 원클릭으로 추가. 이모지 선택도 지원.

💾

로컬 스토리지 저장

서버 없이 브라우저에 영구 저장. 새로고침해도 모든 습관과 기록이 유지됨.

🎉

완료 축하 메시지

모든 습관을 완료하면 축하 배너 표시. 작은 보상으로 긍정적 루프를 강화.

데이터 구조

// localStorage 저장 구조 { "habits": [ { "id": 1748000000000, "name": "물 2L 마시기", "emoji": "💧" } ], "log": { "2026-05-16": [1748000000000] } }
🔑

ID로 Date.now() 사용. log는 날짜 키 → 완료된 habit ID 배열로 관리해 스트릭 계산이 O(n)으로 단순.

User Flow

사용자 경험 흐름

처음 방문한 사용자도 30초 안에 첫 습관을 등록하고 체크할 수 있도록 설계했습니다.

1

앱 접속

오늘 날짜·요일이 자동 표시. 텅 빈 화면에 🌱 빈 상태 안내 문구 노출.

2

습관 추가

추천 칩 클릭 또는 직접 입력 후 추가. 이모지 선택으로 개인화.

3

완료 체크

카드 탭 또는 체크버튼 클릭으로 토글. 링 프로그레스 실시간 업데이트.

✓

모두 완료!

🎉 축하 배너 표시. 스트릭 +1. 내일도 이어가고 싶은 동기 부여.
